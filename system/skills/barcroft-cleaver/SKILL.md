# 巴克罗夫特极简飞刀技能 (barcroft-cleaver)

## 理论依据
源自英国著名生理学家约瑟夫·巴克罗夫特爵士（Sir Joseph Barcroft）的极简治学哲学，以及毛泽东《实践论》与《矛盾论》：
1. **巴克罗夫特极简法则**：面对错综复杂、纠缠不清的生命与物理现象，巴克罗夫特总是力排众议，坚决砍掉一切无关紧要的细枝末节，在纷繁复杂的乱象中只死死揪出一个起支配作用的核心主导因素（主要矛盾）。
2. **理性认知的高维跃迁**：从第一步的感性输入（资料/）与第二步的一手实证（笔记/）中跳脱出来，避免一叶障目，完成从碎片事实到系统规律的理性飞跃。
3. **无损标签索引网（`认知/标签.md`）**：在提炼认知的同时，基于统一的标签体系，以“文件路径 + 关联线索”的形式建立高维认知网状索引，既保证底层资料的不可变性，又实现高维知识的快速穿透联动。

## 使用场景
- 当笔记和资料堆积如山、头绪混乱，不知道谁主谁次时；
- 当多智能体系统或复杂业务架构出现混乱纠缠，急需定位唯一核心瓶颈时；
- 提炼课题核心认知、撰写项目立项综述或构筑认知标签网络时。

## 底层执行
```bash
python3 system/skills/barcroft-cleaver/scripts/cleaver.py --notes "碎片笔记或资料要点" --topic "领域代号" --output "认知/极简认知专报.md"
```
