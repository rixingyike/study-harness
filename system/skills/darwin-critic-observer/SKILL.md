# 达尔文打脸笔记与批判性观察技能 (darwin-critic-observer)

## 理论依据
源自百年名著《科学研究的艺术》第八章【观察】与第四章【假说】中查尔斯·达尔文的经典治学心法：
1. **达尔文黄金法则（三分钟打脸抢救机制）**：人类大脑本能偏爱迎合自己假说的事实，而任何违背自身假说、推翻心爱结论的反面观察和刺耳异见，都会在脑海中停留不超过 3 分钟便被潜意识选择性遗忘或合理化粉饰。达尔文立下铁律：一旦发现任何与自己假说相悖的事实、观察或批评，必须立即掏出笔记在 3 分钟内强制记录，逼迫自己直面冷酷真相。
2. **纯粹客观观察与主观解释严格分家**：贝尔纳指出：“许多伪发现并非来自仪器失灵，而是观察者把自己的主观推论当作客观事实记录了下来。” 本技能强制剥离“眼见事实（客观数据/现象）”与“脑中脑补（推论/预期）”，防范假阳性认知自欺。
3. **极限逆向挑刺与反例证伪**：以反方挑剔观察员视角，对研究者当前的“得意结论”展开毁灭性挑刺，指出可能存在的实验盲区、虚假繁荣及未受控伪变量。

## 使用场景
- 当研究者沉浸在“假说完美成立”的兴奋中，需要冷水清醒、严防认知偏差时；
- 当实验中冒出令人不悦、似乎推翻现有论文框架的离群数据时；
- 当他人对你的技术方案提出尖锐批评，需要客观测定其死穴并转化吸收时。

## 底层执行
```bash
python3 system/skills/darwin-critic-observer/scripts/darwin.py --observation "最新观察到的反常矛盾现象" --hypothesis "自己原先认定的得意假说" --output "记录/达尔文打脸笔记.md"
```
