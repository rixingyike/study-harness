# 想象力激发技能 (imagination-spark)

> 理论依据：贝弗里奇《科学研究的艺术》第五章「想象力」  
> 核心心法：**死熬苦干出不了真假说；以 Why 追问目的打破常规边界，以 How 追问微观物理咬合细节，在好奇与松弛中心智自然生发突破火花。**

本技能是专栏第 08 讲配套的研创灵感激发工具。针对用户选中的资料片段或核心技术难题，运行 Why & How 双螺旋提问手艺。

## 双螺旋提问手艺

1. **Why 追问（目的性与跨界突破）**：
   - 为什么该现象偏偏此时此地发生？为什么现有共识理论失效？
   - 跨界意象嫁接，产出 3 个突破常规思维框架的假设火花。
2. **How 追问（微观机理与齿轮咬合）**：
   - 这一变化在底层到底是怎么一步步传导发生的？
   - 像约翰·亨特因见鹿角结扎血管意外发现侧支循环一样，盯死每一个微观物理/逻辑环节。

## 调用方式

作为原生 Agent Skill，智能体识别意图（如“请运用 Why 与 How 提问手艺帮我深度拆解这个难题”）后，自动挂载本技能并执行：
```bash
python3 system/skills/imagination-spark/scripts/spark.py --name "课题名称" --text "课题或反常现象说明..." --output "笔记/想象力激发分析.md"
```
