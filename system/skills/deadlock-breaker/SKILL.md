# 死锁破局急救技能 (deadlock-breaker)

> 理论依据：贝弗里奇《科学研究的艺术》第九章「困难」  
> 核心心法：**在磨损的神经轨道上死磕蛮干只会通往沮丧；拔电源给潜意识让路、拆大山先挑软柿子捏、胡同大爷大白话灵魂拷问，三味药砸碎定势！**

本技能是专栏第 08 讲配套的瓶颈急救工具。当用户在某一个课题或代码难题上卡壳超过一定时间、情绪烦躁时一键触发。

## 破局三味药

1. **第一味药（拔电源 · 强制战略搁置）**：
   - 下达明确冷冻禁令（如冷冻 72 小时禁止碰该文件），清空大脑工作台，给潜意识留出静默拼图气口。
2. **第二味药（拆大山 · 解构软柿子）**：
   - 将庞然大物拆解为 3~4 个解耦小碎块，“专挑最软的柿子捏”，迅速恢复行动动量。
3. **第三味药（胡同大爷会诊 · 常识降维）**：
   - 剥离所有高深专业黑话，用市井做饭修车常识重新叙述，并抛出 2 个直击本质的外行常识拷问，击碎思维定势。

## 调用方式

作为原生 Agent Skill，智能体识别死锁意图后自动挂载并执行：
```bash
python3 system/skills/deadlock-breaker/scripts/breaker.py --name "难题名称" --text "卡壳困境描述..." --output "笔记/死锁解药建议.md"
```
