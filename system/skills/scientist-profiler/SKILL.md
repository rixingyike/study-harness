# 科学家性格画像与潜能诊断技能 (scientist-profiler)

> 理论依据：贝弗里奇《科学研究的艺术》第十一章「科学家」  
> 核心哲学：**世界上几乎没有十全十美的科学家；开拓者往往带有偏执与叛逆；数字外骨骼的使命是补齐人脑的天然性格缺陷。**

本技能是专栏第 07 讲配套的研创前置诊断工具。当学者开始课题或反思自身科研困境时，本技能作为专属 Agent Skill 直接调用诊断引擎。

## 核心诊断四维度

1. **反应型 vs 被动型人格（开拓者土壤）**：
   - 反应型：敢于怀疑既有权威与教科书公理，对教条有强烈生理排斥，适合开辟新大陆；
   - 被动型：顺从接受正规知识传授的“考霸”，难以胜任从零到一的破局。
2. **爱因斯坦科研驱动力三分法**：
   - 竞技场型（解谜快感） / 谋生工作型（体面工具） / 真正献身型（内在神圣召唤）。
3. **“敢出洋相”心理耐受度（弗莱克斯纳之问）**：
   - 能否承受被权威嘲笑为“幼稚想入非非”的社会性风险；在长期无正反馈中是否具备巴斯德式的顽强坚持精神。
4. **认知谱系（推测型浪漫派 vs 条理型古典派）**：
   - 浪漫派点子乱飞但易留烂尾楼；古典派严密求证但缺乏突变冲力。
