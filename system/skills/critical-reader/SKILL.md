# 批判性拆书与文献审阅技能 (critical-reader)

## 理论依据
源自《科学研究的艺术》第一章【准备】与毛泽东《实践论》认识论之感性认识阶段：
1. **拒绝买椟还珠的浮躁摘要**：平庸的文献阅读往往满足于“作者讲了什么”的被动摘要，缺乏独立批判性；而卓越的研究者阅读文献，永远带着挑刺与防骗的冷眼。
2. **知识空白（Gap）与内在矛盾（Contradictions）双重扫描**：
   - 知识空白（Gap）：作者在哪些关键机理上闪烁其词、一笔带过？有哪些尚未被实验验证的前提假定？
   - 内在矛盾（Contradictions）：文献前后的论点是否存在逻辑互搏？与现有权威基线或现实物理常识是否存在尖锐冲突？
3. **沉淀未解缺陷库（`资料/不完美.md`）**：将发现的所有漏洞、薄弱假设与未解之谜归纳沉淀，不回避争议，直接转化为后续假说推演的靶心。

## 使用场景
- 当研读一篇前沿学术论文、开源框架设计方案或技术专著章节时；
- 当需要寻找课题突破口，排查现有技术方案的隐藏死穴时；
- 启动新课题文献调研，构建结构化感性输入时。

## 底层执行
```bash
python3 system/skills/critical-reader/scripts/reader.py --text "待审阅文献文本或章节" --title "文献名称" --output-dir "资料/"
```
