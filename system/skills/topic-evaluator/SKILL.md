# 课题战略审查与四维打分技能 (topic-evaluator)

> 理论依据：贝弗里奇《科学研究的艺术》第十章「战略和战术」  
> 核心心法：**“科学研究的一般战略是：研究时具有明确的目标，但同时保持警觉，注意发现并捕捉意外的时机。”**

本技能是专栏第 07 讲配套的战略抉择与立项体检工具。避免团队在一开始就踏入“行政死抠细节”或“连续攻坚烂尾”的致命死穴。

## 四维量化审查准绳

1. **三级计划分权合理性（满分 30 分）**：
   - 宏观实用层（高层定靶心、解决粮饷）；
   - 中观协作层（技术带头人划定攻坚山头）；
   - 微观自由层（一线研究人员完全自主制定战术，严禁后方瞎指挥）。
2. **理论与应用深度互哺度（满分 25 分）**：
   - 杜绝狭隘实用主义，深入穿透底层机理（“充分理解了问题，就几乎一定能发见有用的事实”）；
   - 应用研究反向滋养、填补基础理论空白。
3. **探索性与发展性风险配比（满分 25 分）**：
   - 探索性冒险（开辟未知领域）与发展性巩固（修筑堤坝精确化）的无缝接力。
4. **战略性搁置与止损机制（满分 20 分）**：
   - 遭遇死锁时的“拔电源”冷冻与潜意识孵化气口；
   - 务实的不可逾越放弃底线。

## 使用方法

### 方式一：终端命令行直接调用
```bash
# 1. 直接审查课题文本
python3 scripts/topic_evaluator.py --title "AI辅助学术拆书系统" --desc "课题规划说明..."

# 2. 从文件读取规划方案并输出战略审查报告
python3 scripts/topic_evaluator.py --title "某国家自然基金项目" --file "proposal.md" --output "认知/课题战略审查报告.md"
```

### 方式二：通过 MCP 工具跨进程调用
直接在对话中触发 `evaluate_topic` 工具：
```json
{
  "topic_title": "课题名称",
  "topic_description": "详细技术路线与分工说明",
  "output_file": "认知/课题战略审查报告.md"
}
```
