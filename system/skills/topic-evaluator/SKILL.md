# 课题战略审查与四维打分技能 (topic-evaluator)

> 理论依据：贝弗里奇《科学研究的艺术》第十章「战略和战术」  
> 核心心法：**“科学研究的一般战略是：研究时具有明确的目标，但同时保持警觉，注意发现并捕捉意外的时机。”**

本技能是专栏第 07 讲配套的战略抉择与立项体检工具。避免团队在一开始就踏入“行政死抠细节”或“连续攻坚烂尾”的致命死穴。

## 四维量化审查准绳

1. **三级计划分权合理性（满分 30 分）**：
   - 宏观实用层（社会痛点与粮饷保障）：该课题是否直击现实或学科最痛的真实空白？是否有明确的奔头？
   - 中观协作层（战略主攻山头）：是否有清晰的技术防线与主攻方向？
   - 微观自由层（一线战术独立性）：是否严格遵守贝弗里奇铁律——“怎么做实验、怎么写代码必须由一线人员完全自主定夺，行政指导人员切不可在战术上发号施令（人们只能计划科学研究，不能计划新发现）”？
2. **理论与应用深度互哺度（满分 25 分）**：
   - 杜绝狭隘实用主义：战术上是否避免了死盯某一个狭窄的实际用途，而是致力于摸清底层生物/物理/数学机理（“充分理解了问题，就几乎一定能发见有用的事实”）？
   - 理论反哺价值：在推进应用研究的同时，是否能反向填补基础理论的空白？
3. **探索性与发展性风险配比（满分 25 分）**：
   - 冒险突破（探索性侧）：是否具有在边缘交叉学科冒险开拓新大陆的野心？
   - 稳妥巩固（发展性侧）：夺取新阵地后，是否有步骤、有条理地进行精确化、定量化修筑堤坝（避免狂热烂尾）？
4. **战略性搁置与止损机制（满分 20 分）**：
   - 潜意识孵化气口：当遇到“山穷水尽”的思维死锁时，是否设立了“暂时搁置几天或几个月，给潜意识留出拼图时间”的缓冲机制？
   - 务实放弃底线：是否清醒划定了“基于当前技术水平确实无法解决”时的果断放弃条件，防止团队被理想主义拖入无底深渊？

## 规范调用方式

### 方式一：通过 MCP 服务协议调用 (首选)
直接在对话中触发 `evaluate_topic` 工具：
```json
{
  "topic_title": "课题名称",
  "topic_description": "详细技术路线与分工说明",
  "output_file": "认知/课题战略审查报告.md"
}
```

### 方式二：作为原生 Agent Skill 意图触发
智能体识别课题评估意图后，自动挂载本技能或调度底层执行模块：
```bash
python3 system/skills/topic-evaluator/scripts/evaluator.py --title "课题名称" --desc "课题规划说明..." --output "认知/课题战略审查报告.md"
```
