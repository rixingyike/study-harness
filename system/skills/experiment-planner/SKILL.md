# 实验策划技能 (experiment-planner)

## 理论依据
源自百年名著《科学研究的艺术》第二章【实验】。贝弗里奇立下实验设计铁律：
1. **渐进三步法策划**：严禁一上来就搞大而全的决战实验，强制分为：
   - ① Pilot 极小试点（最低成本摸探信号窗口与边界）；
   - ② 大稀释度摸底观测；
   - ③ 大范围海选筛选试验。
2. **严密对照防骗审查（Control Baseline）**：吸取解剖大师约翰·亨特因缺乏对照组把淋病与梅毒混为一谈误导医学半个世纪的惨痛教训，实验必须设立严格的阴性/阳性基线对照，严禁无对照妄下结论。
3. **单一变量与逐步排除法**：一次只改变一个条件，优先做最简单关键的决定性实验，用逐步排除法迅速缩小包围圈。

## 使用场景
- 当研究者提出新假说，不知如何以最低成本启动实验验证时；
- 当实验涉及多变量、大规模算力或复杂样本，需要排查自欺漏洞与伪相关时；
- 撰写立项申请书或开题报告中的“实验技术方案与对照设计”时。

## 底层执行
```bash
python3 system/skills/experiment-planner/scripts/planner.py --query "研究假说或实验需求" --topic "课题代号" --output "假说/实验策划书.md"
```
